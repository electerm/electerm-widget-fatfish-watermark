Fatfish watermark

Two artwork styles, both drawn at the widget's default 20% opacity and 78% height. Original PNG is the default: the untouched MIT sprite, which already spans white headdress to near-black outline, so it stays readable on dark, light and coloured themes. Colour pixel art is the same character reduced to an 8-colour grid. Every tile is a mock terminal on a different theme.

Source. The MIT-licensed chibi sprite is shipped untouched as assets/source-front.png (255 × 340).
Pixel version. npm run build reduces it to a 51 × 68 grid of flat 10px blocks quantised to eight colours — deep blue hair, bright blue tips, white headdress and apron, ink outlines, skin, gold trim — and writes assets/fatfish-pixel-art.png (510 × 680).
Injection. The chosen PNG is inlined as a data URL into one rule in style.css; the other rule is stripped out, so a window only ever carries the image it is actually showing.
